
# Docker — Day 1

## Learning objectives

- Understand what Docker is and why developers use it.
- Distinguish images, containers, and Dockerfiles.
- Run a test container.
- Inspect images and containers.
- Containerize a simple Python application.
- Understand how Docker fits into CI/CD.

## 1. What is Docker?

Docker is a platform for packaging and running applications in containers.

Containers help applications run consistently across different environments.

## 2. Why use Docker?

- Consistent environments
- Dependency management
- Application isolation
- Easier testing and deployment
- Integration with CI/CD pipelines

## 3. Core concepts

### Image
A template used to create containers.

### Container
An isolated running instance created from an image.

### Dockerfile
A text file containing instructions for building an image.

## 4. Basic workflow

Dockerfile -> Image -> Container
